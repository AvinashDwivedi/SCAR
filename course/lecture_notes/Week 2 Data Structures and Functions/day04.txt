### **Day 4: Sets and Set Operations**

---

#### **Topics Covered:**

1. **Introduction to Sets**
   - **Definition**: A set is an unordered collection of unique elements in Python. Sets do not allow duplicate elements and are commonly used when you want to store unique items.
   - **Creating Sets**:  
     You can create a set using curly braces `{}` or the `set()` function.  
     ```python
     my_set = {1, 2, 3, 4}
     another_set = set([5, 6, 7])
     ```
   - **Empty Set**:  
     An empty set is created using the `set()` constructor, not `{}` (because `{}` creates an empty dictionary).
     ```python
     empty_set = set()
     ```
   - **Accessing Elements**:  
     You **cannot** access elements by indexing in sets. Sets are unordered, so their elements do not have a fixed position.
     ```python
     my_set = {1, 2, 3, 4}
     # print(my_set[0])  # This will raise an error!
     ```
     However, you can iterate over the set using a loop:
     ```python
     for item in my_set:
         print(item)
     ```

2. **Set Operations**
   - **Adding Elements**:  
     Use `add()` to add a single element to a set.
     ```python
     my_set.add(5)
     ```
   - **Removing Elements**:  
     Use `remove()` to remove an element from a set. If the element is not found, it raises a `KeyError`. You can also use `discard()` to remove an element without raising an error.
     ```python
     my_set.remove(5)  # Raises KeyError if element is not found
     my_set.discard(3)  # Does not raise an error if element is not found
     ```
   - **Set Union**:  
     Use the `|` operator or the `union()` method to combine two sets, which removes duplicates.
     ```python
     set1 = {1, 2, 3}
     set2 = {3, 4, 5}
     result = set1 | set2  # Output: {1, 2, 3, 4, 5}
     # or
     result = set1.union(set2)
     ```
   - **Set Intersection**:  
     Use the `&` operator or the `intersection()` method to get common elements between two sets.
     ```python
     set1 = {1, 2, 3}
     set2 = {3, 4, 5}
     result = set1 & set2  # Output: {3}
     # or
     result = set1.intersection(set2)
     ```
   - **Set Difference**:  
     Use the `-` operator or the `difference()` method to find elements that are in one set but not in the other.
     ```python
     set1 = {1, 2, 3}
     set2 = {3, 4, 5}
     result = set1 - set2  # Output: {1, 2}
     # or
     result = set1.difference(set2)
     ```
   - **Set Symmetric Difference**:  
     Use the `^` operator or the `symmetric_difference()` method to get elements that are in either of the sets but not in both.
     ```python
     set1 = {1, 2, 3}
     set2 = {3, 4, 5}
     result = set1 ^ set2  # Output: {1, 2, 4, 5}
     # or
     result = set1.symmetric_difference(set2)
     ```

3. **Applications of Sets**
   - **Removing Duplicates from a List**:  
     A common use of sets is to eliminate duplicates from a list.
     ```python
     my_list = [1, 2, 3, 3, 4, 4, 5]
     my_set = set(my_list)
     print(my_set)  # Output: {1, 2, 3, 4, 5}
     ```
   - **Checking for Subset or Superset**:  
     You can check if one set is a subset or superset of another using the `issubset()` and `issuperset()` methods.
     ```python
     set1 = {1, 2, 3}
     set2 = {1, 2, 3, 4, 5}
     print(set1.issubset(set2))  # Output: True
     print(set2.issuperset(set1))  # Output: True
     ```

---

#### **Key Concepts Summary:**

- **Sets** are unordered collections of unique elements. They provide fast membership testing and are ideal for removing duplicates and performing mathematical operations like union, intersection, and difference.
- Key set operations include `add()`, `remove()`, `union()`, `intersection()`, `difference()`, and `symmetric_difference()`.
- Sets are useful in problems involving uniqueness and collection comparisons (e.g., finding common elements, removing duplicates).
