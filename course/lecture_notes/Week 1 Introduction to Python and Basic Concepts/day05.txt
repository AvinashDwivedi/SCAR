### **Introduction to Loops**

Loops are used to execute a block of code multiple times until a condition is met.

#### **for Loop**
- Iterates over a sequence (e.g., list, string, range).
  ```python
  for i in range(5):
      print(i)
  ```

#### **while Loop**
- Executes as long as the condition is `True`.
  ```python
  x = 0
  while x < 5:
      print(x)
      x += 1
  ```

---

### **Control Statements**

#### **break**
- Exits the loop prematurely.
  ```python
  for i in range(10):
      if i == 5:
          break
      print(i)
  ```

#### **continue**
- Skips the current iteration and moves to the next one.
  ```python
  for i in range(5):
      if i == 3:
          continue
      print(i)
  ```

#### **pass**
- Acts as a placeholder; does nothing.
  ```python
  for i in range(5):
      if i == 3:
          pass
      print(i)
  ```

### **Practice Activity**
1. Write a program to print all even numbers from 1 to 20 using a `for` loop.
2. Create a program to calculate the factorial of a number using a `while` loop.
3. Write a program that uses `break` to stop a loop when a user enters a specific keyword.

**Example Code:**
```python
# Print even numbers
for num in range(1, 21):
    if num % 2 == 0:
        print(num)

# Factorial using while loop
n = int(input("Enter a number: "))
factorial = 1
while n > 0:
    factorial *= n
    n -= 1
print("Factorial is", factorial)

# Break on specific keyword
while True:
    word = input("Enter a word (type 'exit' to stop): ")
    if word == 'exit':
        print("Exiting loop.")
        break
    print("You entered:", word)
```
