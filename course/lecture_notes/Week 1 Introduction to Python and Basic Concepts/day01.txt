### **Introduction to Python**

#### **What is Python?**
- Python is a high-level, interpreted programming language known for its simplicity and readability.
- Created by Guido van Rossum in 1991.
- Open-source and widely supported by an active community.

#### **Key Features of Python**
- **Simple and Easy to Learn**: Python has an English-like syntax.
- **Versatile**: Used in web development, data science, AI, machine learning, automation, and more.
- **Cross-Platform**: Runs on Windows, macOS, Linux, etc.
- **Rich Library Support**: Offers extensive libraries for various tasks.

#### **Popular Use Cases**
- **Web Development**: Frameworks like Django and Flask.
- **Data Science and Machine Learning**: Libraries such as pandas, NumPy, and TensorFlow.
- **Automation**: Writing scripts to automate repetitive tasks.
- **Game Development**: Libraries like Pygame.

---

### **Setting Up Python**

#### **Installation Options**
- **Anaconda**: A distribution for Python and R, ideal for data science and machine learning.
- **IDLE**: The default Python IDE.
- **VS Code**: A lightweight editor with Python support via extensions.

#### **Steps to Install Python (Using Anaconda)**
1. Download Anaconda from the [official website](https://www.anaconda.com/products/distribution).
2. Run the installer and follow the on-screen instructions.
3. Verify the installation:
   - Open the Anaconda Navigator.
   - Launch Jupyter Notebook or Spyder to start coding.

#### **Setting Up Your First Python Program**
1. Open a Python editor (IDLE, VS Code, or Jupyter Notebook).
2. Write the following code:
   ```python
   print("Hello, World!")
   ```
3. Run the program to see the output: `Hello, World!`
